# CHANGELOG

- Prefer the Workflow node size over stale dedicated size properties.
- Serialize the current size without mutating live node properties.
- Exclude custom displays from the Workflow Overview parameter editor to prevent canvas width overrides.
- Add seven frontend regression tests for size restoration and read-only serialization.
